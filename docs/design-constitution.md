这里只说明从哪里改，以及哪些改动必须看真实页面。旧 HTML 样稿不是需求，也不能证明现有页面已经实现某个功能。

2026-10-05 用户要求：页面修改先给真实本地站的前后对比图，确认后再落实。命令见 [README](../README.md)。先保持现有设计，不顺便加说明小字或改视觉。

`App.css` 的导入顺序决定样式覆盖。共享规则先于页面规则，窄屏修正在最后。不要只为拆文件就改成按路由加载，否则同一页面可能因访问顺序不同而变样。

删除样式前要查 JSX、动态类名和脚本生成的内容。旧前缀本身不能证明代码没用。修改共享规则后，要实际查看所有受影响页面。

首页登录后会增加一页。改页序、翻页或登录展开时，要同时验证登录前后、退出、动画结束和窗口缩放。其他页面检查手机与桌面的对齐、断行、横向溢出、按钮状态和键盘焦点。

## 内页顶栏与小字（2026-11-21 作者确认）

内页顶栏以答疑页的「← Accueil」和「Conversations」为样板。阅读档案、阅读文章、书架、账号表单和 404 页眉共用 `PageNav`。手机和桌面的导航文字都是 16px。法语保留原有大小写和正常字距。首页沿用翻页刊头。

本轮只删除 11 月 21 日清单中标为「删」且当前页面仍显示的原文。首页阅读和答疑引导页的页码只在左下角显示。重置密码时，账号确认和密码更新各保留一条提示。

答疑列表右上角显示「管理」。点开后，按钮变为「完成」，每段已有对话的行末出现酒红色「删除」。点「删除」后，标题变成和日期相同的灰色。删除线从左向右画出。删除成功且删除线画完后，该行淡出并收起。删除失败时，删除线收回，标题恢复原色。开启「减少动态效果」时，删除成功的行直接消失。按钮文字为 16px，可用 Tab 移到按钮，再按回车或空格操作。

## 字号（作者 2026-11-22 确认）

说明性小字不留。页码、日期、天气、标签和切换项等标注沿用现有字号。作者看过统一放大到 15px 和分别使用 14px、12px 的两版后，决定保留线上原样。

## 页面之间的动作（2026-11-21 作者确认）

| 操作 | 画面 |
| --- | --- |
| 阅读正面与背面互换 | 点 Verso，整张纸绕中央竖轴向左翻半圈。点 Recto，纸沿原路翻回。前半程只看得到原来的一面。转到侧面时只剩纸边，随后才看到另一面。翻到的一面从顶部开始。 |
| 阅读档案打开文章、对话列表打开对话 | 正文从下方升起。点 Archives、Conversations 或用浏览器后退时，正文沿原路向下收回。列表停在打开详情前的位置。 |
| 答疑登录门、首页内嵌登录打开独立表单 | 目标页从右侧翻入，返回时从左侧翻回。未登录时，从辅助表单返回首页会重新显示内嵌登录屏。 |
| 独立登录表单与欢迎页互换 | 登录时表单向左右分开，露出欢迎页。退出时两半合拢，还原表单。开合动作沿用首页 Parole。 |
| 打开或离开重置密码页 | 从邮件直接打开时，表单从右侧翻入，标题不参与横翻。返回登录页或首页时从左侧翻回。 |

表中的翻面、上抽和横翻都是 0.5 秒，沿用 `--flip-ease`。登录屏开合沿用首页的 0.62 秒。系统开启「减少动态效果」时直接切换。手机和桌面都要检查动画中途的画面。阅读翻到正侧面时，纸边两旁应是空白。其他页面衔接时，正文应持续可见。所有动作都要检查横向溢出。
