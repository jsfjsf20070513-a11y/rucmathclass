# 还没解决的问题

下面是从代码、测试和现场核验确认的缺口。它不是扩展产品的计划；先把现有功能和维护边界整理稳。修改相关模块时同步更新这一页，不保留已经完成的待办。

班级站前端、AI Worker 和天气所需的 CSP 已于 2026-09-27 发布并完成公开页面、静态文件及接口拒绝行为核验，见 [发布记录](development.md#最近一次发布核验)。Raccord 的代码、发布目标与数据库已经分开；独立项目的初始化、权限核验和本地接入已完成，没有复制账号或个人记录，详情见 [架构说明](architecture.md#与-raccord-的边界)。

## 1. 真实账号和外部服务的完整流程

这次发布已核验未登录和失效令牌被拒绝，尚未用真实班级站账号完成登录、AI 回答、对话保存与刷新读取，也没有调用真实模型。背词保存、跨账号切换和邮件流程仍需现有账号验证。模拟账号测试通过不能替代这些验收。

生产 Worker 的语音缓存、客户端断开连接和模型配额没有实测。背词朗读使用浏览器，不经过这个语音接口。聊天模型列表查询失败时会使用写死的候选名称，代码不能证明这些模型当前一定可用；不要承诺“免费”或“始终可用”。

## 2. Raccord 尚未首次发布

2026-09-27 核验服务器：班级站实际目录为 `/var/www/MathClassWebsite/dist`；Raccord 目录不存在，也没有启用对应的 Nginx 站点。默认站点会把未匹配域名重定向到班级站，与 Raccord 的公开 301 响应一致。Cloudflare 的 DNS 和重定向规则未获得读取权限，不能据此排除边缘规则。当前 SSH 使用 root，不能宣称服务器账号权限已隔离。

Cloudflare 当前只有班级站的聊天和语音路由，均绑定 `mathclass-ai`；没有 Raccord Worker 路由。Raccord 首发是单独的发布工作，其 Worker 仍需补登录校验，新认证项目也需设置回调并验证真实邮件和账号流程，不能把分库完成当作 Raccord 已上线。

## 3. 现有检查的覆盖范围

导入边界已有 lint 约束，天气请求和动画生命周期也已有独立测试，hook 的 Supabase 导入也已禁止。这仍不是完整的架构验证。

CI 已加入 Chromium 的窄屏与桌面公开流程、模拟登录后的背词和答疑、平板导航及下载失败恢复检查，页面可见性包含透明度、视口位置与祖先裁切。答疑检查包括带令牌发送、认证失败后保留问题、保存后刷新读取。它不覆盖 Safari、真实移动设备、真实认证服务或完整跨账号流程。Worker 已纳入 lint，除模拟接口单测外，还在 workerd 中检查身份校验和重定向行为；这次已用它复现并修复 Node 测试遗漏的运行时差异。

共用导航、翻页、文字按钮和提示样式已从首页、背词文件移到共享层，页面通过组件传入各自行为。基础样式的旧页面残留已清理，账号表单已归回登录样式。全局字体、窄屏留白和共享控件仍会影响多个页面；改这些规则需要实际页面验证。测试目标是发现真实顺序错误，不是单纯增加数量。
