# 还没解决的问题

下面是从代码、测试和现场核验确认的缺口。它不是扩展产品的计划；先把现有功能和维护边界整理稳。修改相关模块时同步更新这一页，不保留已经完成的待办。

Raccord 的代码、发布目标与数据库已经分开；独立项目的初始化、权限核验和本地接入已完成，没有复制账号或个人记录，详情见 [架构说明](architecture.md#与-raccord-的边界)。以下保留实际发布和使用验收中尚未完成的部分。

## 1. 班级站的新前端和 Worker 尚未发布

2026-09-27 只读核验服务器：班级站实际目录为 `/var/www/MathClassWebsite/dist`；Raccord 目录不存在，也没有启用对应的 Nginx 站点。当前默认站点会把未匹配域名重定向到班级站，与 Raccord 的公开 301 响应一致。Cloudflare 的 DNS 和重定向规则未获得读取权限，不能据此排除边缘规则。当前 SSH 使用 root，不能宣称服务器账号权限已隔离。

班级站公开 health 仍是 2026-09-04 构建。线上 CSP 仍包含 Solana devnet，未包含首页天气的 Open-Meteo；仓库里的修正尚未上线。部署脚本已默认离线检查，固定目标目录并核验仓库、主分支和干净工作区。实际发布仍须用户授权。

相册建表、存储桶和综合授权保留在 `sql/legacy/`，与现役表定义、权限修正和只读核查分开。班级站的生产变更仅包含已批准的四张表授权，执行后的权限和匿名接口检查已通过；没有读取或修改个人记录，没有重跑历史 SQL。

仓库已让聊天和语音经过同一身份校验；前端带当前账号令牌，Worker 向 Supabase 核实。限流故障或校验超时会停止处理。线上仍运行 2026-08-20 的无认证版本。发布时需配置 Worker 的 `SUPABASE_URL`、`SUPABASE_ANON_KEY`，与前端一起核对真实登录、对话及保存流程；旧页面需刷新。当前生产配置未更新，也未调用真实模型。

Cloudflare 当前只有班级站的聊天和语音路由，均绑定 `mathclass-ai`；没有 Raccord Worker 路由。Raccord 首发是单独的发布工作，其 Worker 仍需补登录校验，新认证项目也需设置回调并验证真实邮件和账号流程，不能把分库完成当作 Raccord 已上线。

## 2. 现有检查的覆盖范围

导入边界已有 lint 约束，天气请求和动画生命周期也已有独立测试，hook 的 Supabase 导入也已禁止。这仍不是完整的架构验证。

CI 已加入 Chromium 的窄屏与桌面公开流程、模拟登录后的背词和答疑、平板导航及下载失败恢复检查，页面可见性包含透明度、视口位置与祖先裁切。答疑检查包括带令牌发送、认证失败后保留问题、保存后刷新读取。它不覆盖 Safari、真实移动设备、真实认证服务或完整跨账号流程。Worker 已纳入 lint，并覆盖权限、限流故障、语音、流式输入上限和取消；生产缓存、连接断开和模型可用性没有实测。

共用导航、翻页、文字按钮和提示样式已从首页、背词文件移到共享层，页面通过组件传入各自行为。基础样式的旧页面残留已清理，账号表单已归回登录样式。全局字体、窄屏留白和共享控件仍会影响多个页面；改这些规则需要实际页面验证。测试目标是发现真实顺序错误，不是单纯增加数量。

背词朗读使用浏览器，未启用的 Worker 播放分支已删除；Worker 语音接口仍保留，要求认证，有 20 秒超时与音频格式检查。聊天模型列表查询失败时会使用写死的候选名称，代码不能证明这些模型当前一定可用。不要在说明里承诺“免费”或“始终可用”。
