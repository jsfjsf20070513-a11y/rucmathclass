- 答疑：用中文输入法按回车选词时，可能提前发送问题。
- 背词：答题反馈中的全局回车处理，会抢走链接和重试按钮的键盘操作。
- 配对题：不同词条可以有相同中文释义，用户看到相同选项却可能被判错。

- 路由：地址末尾多一个 `/` 时，部分页面会多出通用页眉页脚。
- 空列表：提示建议更换“主题”，但页面没有这个选项。
